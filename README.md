# How does an election forecast model work?

**GRAD-E1493: Data Journalism · Hertie School · May 2026**

An interactive explainer on how zweitstimme.org forecast the 2025 Bundestagswahl, covering both the Zweitstimme (national vote share) and Erststimme (constituency) models.

**[View the explainer](https://data-journalism-26.github.io/final-project-chirag_final/)**

---

## What this is

A scrollytelling explainer that walks through the zweitstimme.org forecast methodology ingredient by ingredient — from historical baselines and poll aggregation to house effect correction, uncertainty quantification, and constituency-level prediction.

## How to reproduce

Install dependencies:
```r
install.packages(c("tidyverse", "httr", "jsonlite"))
```

Run the pipeline from the project root:
```r
source("zweitstimme_pipeline.R")
```

This fetches live poll data from the Zweitstimme API, downloads the constituency model predictions from the [replication repo](https://github.com/zweitstimme-org/prediction-2025-replication), and reads the archived input files from `data/input/`.

## Data sources

- Poll data and forecast: [zweitstimme.org](https://zweitstimme.org) via api.fasttrack29.com
- 2025 official results: [Bundeswahlleiterin open data](https://www.bundeswahlleiterin.de)
- Constituency model predictions: [zweitstimme-org/prediction-2025-replication](https://github.com/zweitstimme-org/prediction-2025-replication)
